# Marketing-E_commerce-Project
Project Description

A comprehensive dashboard project for analyzing sales and marketing data using Python and Plotly.
The project showcases overall company performance, customer journey, marketing campaigns, and provides interactive future revenue predictions ready for visualization.
## Project Objectives
### 1-Analyze sales performance and key KPIs:
   * Total Revenue 
   
   * Number of Orders
   
   * Average Order Value (AOV)
   
   * Refund Rate

### 2-Study the customer journey through Funnel Analysis:
  * Views → Add to Cart → Purchase Conversion

### 3-Analyze customer behavior using RFM Analysis:
   * Recency, Frequency, Monetary

### 4-Evaluate marketing campaign performance:
   * Campaign Performance (Bar & Pie Charts)

### 5-Build a Predictive Revenue Model:
   * Actual vs Predicted Revenue per Month

### 6-Create an interactive dashboard ready for strategic decision-making.
